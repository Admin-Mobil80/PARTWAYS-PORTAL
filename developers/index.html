PartWays API

Start exit interviews from your HR system. When someone resigns, your HR system adds them to a PartWays programme, and PartWays sends their invitation by email and/or WhatsApp. You can follow each invitation’s progress and cancel it if the resignation is withdrawn.

Getting started

  1. Sign in to your PartWays workspace as an owner and activate the programme people should be invited to.
  2. Go to Settings → API access, choose Create API key and name it after the system that will use it. Copy the key: it is shown once.
  3. Store the key in your HR system’s secure settings and call the API from your server or integration platform. The API is not meant to be called from a web browser.

Base URL: https://partways.org/api/v1. Requests and responses are JSON. Each invitation sent uses one credit, exactly as when it is sent from the workspace.

Authentication

Send the key in the Authorization header. X-API-Key: <key> is also accepted.

Authorization: Bearer pw_live_3f9a0c1d2e4b_…

A key acts for your organisation’s workspace with the rights of an owner, for invitations only. Revoke a key in Settings → API access at any time; systems using it stop working straight away. Keys show when they were last used.

Typical HR-system flow

In your HR systemCall
Set-up: choose which programme to useGET /programmes
A resignation is recordedPOST /invitations with your case or employee reference as externalId
Show progress on the leaver’s recordGET /invitations/{interviewId}, or GET /invitations?externalId=…
The resignation is withdrawnPOST /invitations/{interviewId}/cancel

Retries are safe. With an externalId, repeating POST /invitations returns the invitation already made (200, "created": false) instead of inviting the person twice or using another credit.

Endpoints

GET

/programmes

Your programmes that are not archived. Invitations can only be sent for programmes whose status is active.

curl https://partways.org/api/v1/programmes \
  -H "Authorization: Bearer $PARTWAYS_API_KEY"

{
  "programmes": [
    { "id": "prog_276e8840b041", "name": "Exit interviews", "status": "active", "template": "general" }
  ]
}
POST

/invitations

Adds a departing employee to a programme and sends their invitation. Give an email address, a mobile number, or both; the invitation goes to every channel given. No name is needed: each person gets a PartWays Interview Id.

FieldTypeDescription

mobilestringWhatsApp number in international format, for example +44 7700 900123. A local number starting with 0 takes your organisation’s country code.
externalIdstring, up to 100Your reference for this leaver or case, used to find the invitation and to make retries safe. Use an opaque id, not a name.
departureDatestringYYYY-MM-DD.
businessUnit, function, locationstringSegments for findings. Results for any group with fewer than 3 responses are hidden.

If the person was added but a message could not be delivered, the response is still 201 with a sendError; no credit is used, and you can retry with POST /invitations/{interviewId}/send. Non-standard tenure bands or role levels are kept as written and reported in warnings.

GET

/invitations/{interviewId}

One invitation by its PartWays Interview Id.

GET

/invitations

Invitations made in your workspace, newest first. Optional query parameters: externalId, programmeId, status, limit (1–100, default 50). Returns { "invitations": [...], "total": n }.

POST

/invitations/{interviewId}/send

Sends an invitation that was added with "send": false, or that could not be delivered. Uses one credit.

POST

/invitations/{interviewId}/cancel

Cancels an invitation, for example when a resignation is withdrawn. The link stops working. Feedback that has been submitted cannot be cancelled. Credits are not returned.

The invitation object

FieldDescription
interviewIdThe PartWays Interview Id, for example PW-7KQ2-M4XD. The person sees it in their invitation.
programmeId, externalId, departureDateAs given.
statusWhere the person is: see Statuses.
invitation.statusprepared (not sent yet), sent or cancelled.
invitation.channelsemail and/or whatsapp.
invitation.sentAt, openedAtWhen the invitation was sent and first opened.
invitation.deadlineLast day to respond, 21 days after the invitation is added.
invitation.remindersSent, deliveredReminders sent so far; whether at least one channel was delivered.
submittedAtWhen the person submitted their feedback, or null.

Errors

Errors return a JSON body with a readable error and, for most errors, a details.code:

402 Payment Required
{ "error": "You have no interview credits left. …", "details": { "code": "no_credits" } }
StatusWhen
400Invalid request, for example no email or mobile, or an invalid number (invalid).
401Missing, invalid or revoked API key (unauthorized).
402No credits left (no_credits). Use Request more credits in the workspace.
404Programme or invitation not found in your workspace (not_found).
409The programme is not active, the person was already invited to this programme with that email or mobile (duplicate), or the invitation was already sent or cancelled.
502No message could be delivered. Nothing was charged; try again later.

Privacy

  • The API never returns interview content, summaries or quotes, and never returns the email address or mobile number you sent. Findings are in your workspace, in aggregate.
  • Send only what the invitation needs: a personal email address and/or mobile number, plus the optional segments. Do not send names or reasons for leaving.
  • Use an opaque reference as externalId. It links the invitation to your record so you can follow progress; PartWays does not use it in findings.
